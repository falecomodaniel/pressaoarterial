# Pressão PWA

Versão instalável do aplicativo de acompanhamento de pressão arterial.

## Recursos

- instalação como aplicativo no computador ou celular;
- funcionamento offline após o primeiro acesso;
- edição de medições existentes;
- confirmação antes de excluir uma medição;
- ícones próprios para PWA e atalho do Windows;
- contato discreto com o desenvolvedor;
- dados mantidos somente no dispositivo do usuário.

## Uso local

1. Execute `npm run build`.
2. Execute `npm start`.
3. Abra `http://127.0.0.1:4173` em um navegador compatível.

Para instalar como PWA e distribuir para outras pessoas, publique a pasta em um endereço HTTPS.
